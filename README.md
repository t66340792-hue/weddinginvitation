# Eswai & Veena

Build a Premium Indian Wedding Invitation Website

Create a beautiful, premium, highly responsive Indian wedding invitation website based on the uploaded invitation images.

The uploaded images are the primary visual reference for the website. Analyze their typography, colors, borders, illustrations, floral patterns, spacing, and traditional Indian aesthetic, and carry the same design language throughout the website.

The website should feel like a luxury digital wedding invitation, not a normal business website.

2. Overall Visual Design

The entire website must match the uploaded invitation cards.

Primary color palette

Use colors inspired directly from the invitation:

Sage / muted olive green background

Soft pastel pink / blush

Warm ivory / cream

Muted gold

Dark olive green

Very subtle darker green overlays

The main background should use the same sage-green floral aesthetic visible in the invitation.

Use subtle floral patterns in the background rather than plain solid colors.

Borders

Use decorative traditional Indian/Kolam-inspired borders similar to the invitation images.

The border should:

Appear around major sections

Be subtle and elegant

Use pastel pink/cream

Never interfere with readability

Adapt properly on mobile screens

Typography

Use an elegant combination of:

Luxury calligraphy/script font for names and section headings

Classic serif font for wedding details

Clean readable serif/sans-serif font for smaller information

Suggested font combinations:

Great Vibes / Allura / Cormorant Garamond for decorative headings

Cormorant Garamond / Playfair Display for main text

Lora / Libre Baskerville for supporting text

Do not use generic modern fonts for the main wedding names.
